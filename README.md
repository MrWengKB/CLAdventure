# 冒险30天

一个在浏览器中运行的文字冒险小游戏。

## 规则

- 初始：生命 100（生命上限 100）、防御 10、金币 200、经验 0、等级 1。
- 每开启新的一天，需要答对一道随机问题（`questions.csv`，四选一，选项顺序随机）。答错会显示正确答案并换一道题重试。
- 连续答错惩罚（答对即清零）：错 1 题不罚；连错 2 题扣 10 金币；连错 3 题再扣 10 点生命（不受防御影响）；连错 4 题直接失败。
- 新的一天触发一个随机事件（`event.csv`），数值为增减量；`full` 表示回满生命。空白视为 0。事件按顺序结算：
  1. 生命：负数先加上防御值，就是最终伤害（最多减到 0，不会变成回血）。例如 -20、防御 10，最终 -10。回血不超过当前上限。
  2. 金币可以为负（负债）；经验只增不减。
  3. 生命上限（`maxlife`）：满血时上限变化后仍是满血；不满血时不回血，生命只在超过新上限时被压到新上限（90/100 上限 +10 → 90/110；上限 -15 → 85/85）。
  4. 防御（`defense`）：增减，最低为 0。
  - `life`、`coins`、`maxlife`、`defense` 也可以写 `set N`（如 `set 10`）：只有当前值大于 N 时才变成 N，否则不变（不会变相回血或加钱）。set 生命不受防御影响；set 生命上限时，生命按上面第 3 条规则处理。经验不支持 set，但可以写 `full`（经验补到下一级所需，即马上升一级）或 `double`（经验翻倍，经验为 0 时视为 +5；翻倍后如果达到升级门槛，就视为 `full`，只升一级）。
  - 也可以写 `double`（翻倍）或 `half`（减半，奇数向上取整）。生命翻倍不超过当前上限，生命减半不受防御影响；生命上限翻倍 / 减半时，生命按上面第 3 条规则处理；防御直接翻倍 / 减半。防御为 0 时 `double` 视为 +30，金币为 0 时 `double` 视为 +100。金币为负数时，`double` 视为 `nodebt`，`half` 不起作用。
  - `coins` 还可以写 `nodebt`：金币为负数时归零（免除债务），否则视为 +30。
- 小商店：随时可用金币购买。防御 +5 / +10 / +15 分别 100 / 180 / 270 金币；生命 +10 / +20 / +30 分别 100 / 180 / 270 金币。解药 1 颗 200 金币，每天限购 1 颗（买过后按钮变灰，第二天恢复）；买的时候如果正在中毒就立刻解毒，否则在之后 4 天内可抵挡一次中毒（规则同事件给的解药）。只有生命大于 0 时能买；金币必须足够（不能借钱买）；生命不会超过上限，满血时不能买生命。
- 等级：经验累计到 30 升 2 级，60 升 3 级，120 升 4 级，210 升 5 级，330 升 6 级……（从 2 级起，每级所需经验比上一级多 30；公式：升到 L 级需要 30 + 15 × (L-1) × (L-2)）。升到 N 级时，生命上限 +N×5（生命按上面第 3 条的上限规则处理，不回血），防御 +N×2，例如升到 2 级 +10 / +4，升到 3 级 +15 / +6；一次获得大量经验可以连升多级。
- 生命为 0 则游戏失败；坚持满 30 天且生命大于 0 则通关。通关或失败都会弹窗提示，需手动关闭或点“再来一局”。
- 事件链：`event.csv` 的 `next` 栏填下一个事件的编号（SN）。抽到这个事件后，第二天必定发生 `next` 指向的事件；填 0 表示没有后续，第二天照常随机。`prev` 栏填前一个事件的编号：填 0 表示可以被随机抽到；不是 0 的事件只会通过事件链出现，不会被单独抽到。例如 32 的 next 是 33、33 的 next 是 34（33 的 prev 是 32、34 的 prev 是 33），就会依次发生 32 → 33 → 34。链上第一个事件的 `linkcount` 栏填整条链的事件个数（例如 32 填 3），其他事件填 0。抽取时会确保整条链能在 30 天内走完：例如三连事件最晚在第 28 天抽到，第 29、30 天不会抽到；两连事件最晚在第 29 天抽到。
- 中毒：`event.csv` 的 `poisoned` 栏填 1 表示这个事件会让你中毒（0 表示不会）。中毒从下一天开始，持续 3 天，每天生命固定 -10，不受防御阻挡。中毒期间再次中毒会叠加：例如第 1 天中毒，第 2、3 天各 -10；第 3 天又中毒，则第 4 天 -20，第 5、6 天各 -10。中毒扣血在当天所有其它效果之前结算；如果毒发让生命归零，游戏直接失败，当天的事件不再发生。中毒扣血不写在生命那一栏，但会显示在当天的效果里。
- 解药：`antidote` 栏填 1 表示获得一颗解药（填几就是几颗，可叠加）。获得时如果正处于中毒状态，立刻解毒（所有中毒都结束），当天不扣中毒的血，用掉一颗。获得时如果没有中毒，解药在之后的 4 天内有效：这期间碰到会中毒的事件，不会中毒，解药 -1；4 天后没用掉的解药失效。

## 导入题库

- 页面上方点“📋 题库格式”可查看格式说明，并下载空白模板。
- 点“📂 导入题库”选择自己的 CSV 文件，导入后从下一道题开始使用新题库（替换默认题库）。刷新页面会恢复默认的 `questions.csv`。
- 格式：每行一道题，5 列 `题干,答案,干扰项1,干扰项2,干扰项3`；表头行可留可删；UTF-8 和 GBK 编码都能识别，可以直接用 Excel / WPS 另存为 CSV。

## 发布作业（不记成绩）

- 老师先选好题库（默认题库，或用“📂 导入题库”导入自己的 CSV），点“📤 发布作业”，填作业标题，点“生成作业链接”。
- 得到一个链接和二维码：可复制链接、下载或打印二维码。学生用平板或手机扫码即可打开。
- 学生打开后直接用这套题玩游戏，页面顶部显示作业标题，看不到“题库格式”“导入题库”“发布作业”按钮，不能换题。
- 不需要服务器、Google Sheet 或 Apps Script：题目压缩后直接放在链接 `#hw=` 后面。不记名、不记成绩。
- 用默认题库发布时，链接里只记“用默认题库”，链接很短；以后修改 `questions.csv`，旧链接也会用新题目。
- 二维码容量有限：中文题大约 30 道以内、英文短题大约 50 道以内才能生成二维码；题目更多时链接仍然可用。

## 数据文件

- `questions.csv`：`Question,Answer,Distractor1,Distractor2,Distractor3`
- `event.csv`：`SN,event,life,coins,exp,defense,maxlife,prev,next,linkcount,poisoned,antidote`
